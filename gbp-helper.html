GBP posting helper

Twelve weeks. Pick a branch tab, copy, paste, add that branch’s own photo, post.

Do not post the same text to all three. Identical text, photo and link pushed to three listings within a few minutes is what automated spam looks like to Google, and posts get filtered. Each tab below already ends with that branch’s own line. Use a different photo per branch, and leave an hour or two between them.
  1. Open business.google.com and pick the branch.
  2. Choose the matching tab below, click Copy text.
  3. Add update → paste → add a photo of that branch → set the button → Post.
  4. Mark it posted, then do the next branch later in the day.
Ticks are saved in this browser only. Posts expire after 7 days. After week 12, start again at week 1 with different photos.
